# INDI+P 공유 UX 100개 개선 감사 — v43

> 실제 100명 인터뷰가 아니라 모바일 UX·데스크톱 UX·SNS 공유·접근성·브라우저 호환성·편집기·오류방지 관점 100개 체크리스트다. 이번 릴리스는 공유가 자동 다운로드로 빠지는 문제를 최우선으로 수정했다.

## 1. 공유 동작 1–10
1. [적용] 공유 버튼에서 자동 다운로드 제거.
2. [적용] 다운로드는 ‘이미지 저장’에서만 수행.
3. [적용] 공유용 PNG를 미리보기 생성 때 캐시.
4. [적용] 공유 클릭 순간 재렌더링하지 않도록 변경.
5. [적용] 사용자 클릭 권한이 살아있는 동안 navigator.share 즉시 호출.
6. [적용] 파일 공유 가능 여부를 canShare로 확인.
7. [적용] 파일 공유가 안 되면 텍스트·URL 네이티브 공유 시도.
8. [적용] 네이티브 공유가 없으면 이미지 클립보드로 전환.
9. [적용] 이미지 클립보드도 안 되면 문구 클립보드로 전환.
10. [적용] 모든 공유 실패 경로에서 강제 다운로드 금지.

## 2. 모바일 공유 11–20
11. [적용] 모바일 ‘바로 공유’ 버튼을 최우선 액션으로 표시.
12. [적용] 공유 이미지 준비 중에는 버튼 비활성화.
13. [적용] 준비 완료 시 버튼을 자동 활성화.
14. [적용] 모바일 Web Share Level 2 파일 공유 우선.
15. [적용] PNG MIME을 image/png로 고정.
16. [적용] 파일명을 .png로 고정.
17. [적용] 제목·비평·태그를 공유 텍스트에 포함.
18. [적용] INDI+P URL을 공유 문구에 포함.
19. [적용] 모바일 네이티브 공유 불가 시 SNS 대체 선택지 노출.
20. [적용] 대체 선택지는 다운로드가 아니라 클립보드 중심.

## 3. 데스크톱 공유 21–30
