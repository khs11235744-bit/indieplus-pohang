# INDI+P 공유카드 UI/UX 전문가 관점 100개 감사 — v40

> 실제 100명을 인터뷰한 기록이 아니라, UI/UX 디자이너·프론트엔드 개발자·접근성 전문가·에디토리얼 디자이너·콘텐츠 PM 등 **100개의 전문가 역할 관점**으로 점검한 실행 목록이다.
>
> 이번 v40의 1차 목표는 사용자가 지적한 **데스크톱 공유카드 편집기의 하단 밀착·잘림·긴 세로 스크롤 문제**를 해결하는 것이다.

## A. 데스크톱 작업창 구조 1–10
1. [적용] 데스크톱 공유 편집기를 하단 바텀시트가 아니라 화면 중앙 작업창으로 고정.
2. [적용] 작업창 최대 폭을 1380px로 제한해 초대형 모니터에서도 시선 이동을 억제.
3. [적용] 작업창 높이를 `100dvh` 기준으로 계산해 브라우저 실제 가용 높이에 맞춤.
4. [적용] 기존 `overflow:hidden` 때문에 하단 컨트롤이 잘리던 구조를 내부 독립 스크롤로 분리.
5. [적용] 화면 가장자리와 작업창 사이 안전 여백을 반응형으로 확보.
6. [적용] 세로 780px 이하 노트북에서 패딩과 미리보기 높이를 자동 축소.
7. [적용] 961–1180px 데스크톱에서 좌우 패널 폭을 별도 최적화.
8. [적용] 960px 이하에서는 모바일용 단일 흐름으로 자동 전환.
9. [적용] 모달 내부 overscroll이 배경 페이지로 전달되지 않도록 차단.
10. [적용] 편집기 열림 중 문서 전체 스크롤을 잠금.

## B. 좌측 편집 패널 11–20
11. [적용] 좌측 설정만 독립적으로 세로 스크롤.
12. [적용] 스크롤바 공간을 미리 확보해 열고 닫을 때 가로 흔들림 방지.
13. [적용] 좌측 패널의 불필요한 가로 스크롤 제거.
14. [적용] 좌측 마지막 컨트롤 아래 충분한 여백을 확보해 하단 밀착 방지.
15. [적용] 편집 단계 툴바를 좌측 상단에 고정.
16. [적용] 디자인·사진·문구·세부조정 빠른 이동 버튼 추가.
17. [적용] 빠른 이동 버튼은 해당 섹션을 좌측 패널 안에서 스크롤하도록 처리.
18. [적용] 좌측 섹션의 시각적 번호 체계를 01–03으로 통일.
19. [적용] 섹션별 보조 설명을 짧게 표시해 현재 작업 위치를 이해하기 쉽게 함.

## C. 우측 미리보기 21–30
21. [적용] 우측 미리보기 패널은 자체 스크롤 대신 고정 작업 영역으로 변경.
22. [적용] ‘실시간 미리보기’ 제목 추가.
23. [적용] 현재 4:5·9:16·1:1 형식을 즉시 확인하는 배지 추가.
24. [적용] 미리보기와 액션바를 같은 우측 패널에 유지.
25. [적용] 미리보기 이미지가 세로 화면에서 잘리지 않도록 최대 높이 제한.
26. [적용] 미리보기 이미지를 `object-fit:contain`으로 표시해 편집 결과 전체 확인.
27. [적용] 미리보기 폭을 410px 이하로 제한해 과도한 확대 방지.
28. [적용] 짧은 노트북 화면에서는 미리보기 최대 높이를 추가 축소.
29. [적용] 미리보기 영역에 접근성용 레이블 추가.
30. [적용] 미리보기 그림자와 배경 대비를 낮춰 결과물 자체가 더 잘 보이게 조정.

## 이번 패치 핵심
- 문제의 직접 원인: 데스크톱에서 시트 높이보다 실제 콘텐츠가 더 긴데 `overflow:hidden`이어서 하단이 잘림.
- 구조적 수정: 좌측 설정 스크롤 / 우측 미리보기+액션 고정.
- 기능은 줄이지 않고, 고급 컨트롤을 접어 기본 편집 흐름을 짧게 만듦.
- 공유 이미지 렌더러와 기존 프리셋 데이터는 그대로 보존.
